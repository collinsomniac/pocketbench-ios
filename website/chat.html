Experimental protocol

Start with Qwen3 0.6B at catalog-default context. Run the known-good probe, then send your own short prompt. If both work, compare a 1,024-token context or the 1.7B model one variable at a time. An 8B catalog listing is not evidence it fits in Safari.

The 64-token probe may emit only an unfinished <think> segment. That proves decoding but not a useful answer. You can increase max_tokens or explicitly add "extra_body":{"enable_thinking":false} in Request JSON *after* the baseline works.

Session checkpoints, including prompts, stay in this browser's localStorage until cleared; the exported JSON is saved on your device. This site sends no prompts to a remote inference API, but runtime and weights are fetched from external hosts when loading.
