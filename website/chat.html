Experiment notes

The 0.6B model completed 64-token inference on this iPhone at 48.72 model-reported decode tokens/s. The other two entries are untested. Larger models may terminate an iOS browser tab without a JavaScript error.

Model memory and execution scope

Runtime catalog estimates will appear here. They do not include observed Safari headroom. The app uses WebLLM 0.2.85 in a dedicated worker, reusing the previously successful backend.

What is retained?

Conversation and diagnostic checkpoints are stored in this browser’s sessionStorage for reload recovery. Export creates a local JSON file. Nothing sends prompts to a cloud inference API. Model files and runtime code are downloaded from external hosts on first load.

Design and runtime comparisons

WebLLM Chat / NextChat offers richer chat UX but adds a substantial app framework. wllama supports GGUF and CPU/GPU offload; our separate GGUF route remains experimental. This page uses native UI and the working WebLLM worker to minimize moving parts.
