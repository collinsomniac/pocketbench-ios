# PocketBench uncapped GPU queue-completed throughput v1

Open `suite-throughput.html` in Safari. The default four-case test begins automatically and runs the existing dual-attractor particle engine with fused integration, no requestAnimationFrame (main or worker), and no visible WebGPU presentation. Save or share the report as JSON. `?autorun=0` disables auto-start.

Cases: 65,536 particles × two steps, offscreen texture 768×390 with batch 16; the same scene at 880×1738 with batch 16; repeat large scene with batch 64; 262,144 particles × eight steps compute-only with batch 16. Each uses a 250ms warmup and 2.5s measured phase. Use the custom form for baseline or other workloads, plus 4/16/64 batch sizes and 1–15-second duration.

Every worker loop submits at most `batch` iterations and then awaits `GPUQueue.onSubmittedWorkDone()` **before counting that batch as completed**. Work cannot accumulate without bound. Render-to-texture cases read back a 16×16 pixel tile **after** the measurement so that the render target is observed. Report contains configurations, actual framebuffer dimensions, completed iterations, particle updates/s, wall time, JS submission time, queue-wait time, per-batch readings, output-tile checksum and environment. Sampling GPU timestamps is intentionally disabled in this throughput experiment; consult the presentation-isolation suite for pass-duration timestamps.

This is neither the screen's presented FPS nor isolated GPU shader throughput. Queue completion does not prove a completed image was presented to the display. CPU encoding, browser dispatch overhead, GPU scheduling and synchronization are included; the batch-size sweep reveals sensitivity to these costs. Offscreen rendering can differ from the canvas/presentation path. The engine retains fixed simulation steps **per iteration**: as iteration rate increases the virtual world advances faster than real time. This benchmark measures identical simulation operations, not refresh-independent real-time physics. No GPU temperature, power, real scanout time, numeric equivalence, or sustained thermal performance is measured. Repeat ABBA and run longer custom durations to assess variation.

`node tests/throughput.mjs` tests bounded-batch counting and queue-drain semantics with a mock. No iPhone WebGPU result exists until running on-device.
