Kernel A/B · workload · notes

The original and fused kernels use the SAME dual-attractor forces, damping, semi-implicit Euler integration, 32-byte particle layout and billboard renderer. Fused mode loads a particle once, applies all substeps in registers, then stores it once. The moving attractors remain fixed within each displayed frame in both modes. The simulation advances a fixed number of substeps PER DISPLAYED FRAME, not per elapsed wall-clock second; this is intentional for comparison with v1.

Measure one setting at a time: baseline → fused → baseline → fused, preferably with rendering OFF first. Use 4–16 steps and 262,144+ particles to expose bandwidth and scheduling differences. GPU pass timers are not total frame duration. Allow thermal recovery and compare median and P10/P90, not only FPS. Do not change settings mid-test.
