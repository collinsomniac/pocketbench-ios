# Active limitations (2026-09-22)

- **Chat first-inference reload, root cause unresolved.** The user reports that Qwen3 1.7B reached model-ready in the original Chat interface but Safari reloaded upon asking a poetry question. That first request differed from a successful Qwen3 0.6B diagnostic in model size, system message, temperature, 128-vs-64 output tokens, and thinking override. No single cause is established. `website/chat.html` v0.2.0 now includes the *exact* successful request as an isolated probe, defaults to a conservative single-user request, supports load-time context overrides and persists pre-inference checkpoints in localStorage. A mocked event-handler/inference test passed; **the revised build has not yet completed real iPhone inference.** See [`CHAT_LAB.md`](CHAT_LAB.md).
- **WebLLM runtime lead:** [mlc-ai/web-llm#844](https://github.com/mlc-ai/web-llm/issues/844) reports a Qwen3 1.7B prefill / GPU shape-cache regression starting at 0.2.83 on a different platform. This does **not** establish that it caused the iPhone reload. Compare same model, request and context before changing runtime versions.
- **GGUF first load unresolved.** A 105,454,144-byte SmolLM2 Q4_K_M was cached; wllama 3.6.1 aborted during initialization and mishandled a non-string abort payload. The consolidated GGUF page removed an import-map self-reference but first inference remains unverified.
- **WebLLM measured control:** `website/ai.html` produced a user-exported Qwen3 0.6B one-token and 64-token run. The 64-token run reported 48.72 decode tokens/s. The one-token request returned `<think>` while usage counted zero completion tokens; avoid treating a thinking-only response as a useful final answer.
- **Deployment:** GitHub Pages previously deployed `main` branch root; root `index.html` redirects into `website/`. Live publication and Safari performance cannot be established with mock tests. Retired experimental pages remain in `archive/pre-two-folder-cleanup-2026-09-22`. The original `website/throughput.html` retains some links to retired routes.

Keep only the two top-level directories, repair existing slugs in place, and do not claim a phone crash is fixed until a completed user-exported run demonstrates it.
